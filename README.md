# Kitchen Remodel Palos Hills

Luxury dark-themed, SEO-optimized landing page targeting **"kitchen remodeling contractor Palos Hills IL"**.

## Files

- `index.html` - Main page (1000+ word semantic article, images, animations, schema markup)
- `robots.txt` - Crawler rules and sitemap location
- `sitemap.xml` - XML sitemap
- `README.md` - This file

## Setup

1. Replace `https://kitchenremodelpaloshills.com/` with your real domain in `index.html` (canonical, og:url, schema), `robots.txt` and `sitemap.xml`.
2. Replace the stock images with your own project photos and keep the descriptive `alt` text.
3. Connect the contact form in `index.html` to your form service or backend.
4. Upload all files to the site root, then submit `sitemap.xml` in Google Search Console.

## Features

- Dark luxury theme with gold accents
- Scroll reveal, hero zoom, shimmer and progress bar animations
- Article, LocalBusiness and FAQ structured data
- Fully responsive with reduced-motion support
